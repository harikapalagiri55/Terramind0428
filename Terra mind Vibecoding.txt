Build a production-quality full-stack web application called **CyberShield — Adaptive Enterprise Phishing Defense & Human Risk Training Platform**.

### OBJECTIVE

Create a working enterprise cybersecurity awareness platform that allows security officers to safely simulate role-based spear-phishing campaigns, measure employee behavior, calculate human vulnerability, and automatically assign targeted micro-training when an employee fails a simulation.

This must be a **fully functional software product**, not a static UI/demo mockup.


The application MUST support this complete live flow:

**Admin creates campaign → selects employee role → launches simulated phishing attack → employee opens employee portal → clicks simulated phishing link → backend immediately records the interaction in the live database → employee risk score increases → account changes to "Remediation Required" → personalized micro-training is automatically assigned → Admin dashboard updates with the new event.**

Every state change must persist after page refresh.

## 9. SECURITY REQUIREMENTS

Follow secure application practices:

* Never expose API keys or database credentials in frontend code.
* Store secrets in environment variables.
* Validate all backend inputs.
* Use proper authentication and authorization.
* Separate Admin and Employee permissions.
* Prevent employees from accessing admin APIs.
* Do not store real passwords from phishing simulations.
* Use safe mock data.
* Protect API endpoints.
* Do not place secrets in client bundles.
